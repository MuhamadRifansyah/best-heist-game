**The Velvet Vault** is a top-down 2D stealth heist game: sneak through a dark museum at night, read the sweeping vision cones of patrolling guards and wall cameras, toss coins to distract them, steal the Star of Velvara gem from its vault, and slip out the exit before the alarm hits 100%.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests — plain static files under `game/`.

**Controls:** WASD / arrows move · Shift sneak (slower, harder to spot) · hold E at the gem to steal it · click to toss a coin and distract a guard · R restart · P pause · M mute.

**Screenshots:** `?shot=cover` shows the full heist in one frame (thief, guards, cameras, loot, alarm meter), `?shot=play` mid-heist, and `?shot=end` the clean getaway.
